# Test plans

Markdown test plans live here — written by you or drafted by the Playwright planner agent
(`npx playwright init-agents --loop=claude` or `--loop=vscode`), then reviewed by you.

One file per feature, for example `specs/cart.md`: numbered scenarios, steps, expected results.
Review every plan before the generator turns it into tests: are the risks covered — boundaries,
negative cases, the €50 free-delivery threshold?
